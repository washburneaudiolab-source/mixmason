# MixMason

**Free for good, from [Washburne Audio Labs](https://washburneaudiolabs.com).** No trial, no subscription, no ads.

Tell it what's plugged in and MixMason shows you how to set every knob on your mixer. The Setup Planner draws the settings on a picture of your mixer, then walks you through them while listening over USB, so you know each step really worked.

**Works with** Mackie ProFX v3 mixers (ProFX6v3, 10v3, 12v3, 16v3, 22v3 and 30v3). Tested on a ProFX12v3; the other models are built from their owner's manuals, so please
tell us how yours goes: washburneaudiolab@gmail.com.

## Download

Windows 10 or 11 (64-bit): **[MixMason-Setup-1.0.0.exe](https://github.com/washburneaudiolab-source/mixmason/releases/latest)** from the latest release.

Your mixer connected to the computer by USB.

The installer isn't signed yet, so Windows may show **"Windows protected your PC"**: choose **More info**, check the
file name, then **Run anyway**. Only download it from this page or washburneaudiolabs.com.
